## 本地开发
```bash
pnpm install        # 安装依赖
pnpm dev            # 启动开发服务器
pnpm build          # 构建到 dist/
pnpm preview        # 预览构建产物
```

## 内容
- 文章：`src/content/posts/*.md`
- 关于页：`src/content/spec/about.md`
- 友情链接：`src/content/friends/*.md`
- 站点配置：`src/config.ts`

## 部署
GitHub Actions 将 `main` 分支构建结果（`dist/`）自动部署到 `gh-pages` 分支，
由 GitHub Pages 以自定义域名 **oct0pu5.cn** 提供服务。
